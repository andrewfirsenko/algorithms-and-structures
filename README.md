# Algorithms and Data Structures

Учебный проект с реализациями классических алгоритмов и структур данных на Swift.
Используется как песочница для практики, подготовки к собеседованиям и решения задач.

## 🚀 Цели проекта

- Закрепить базовые и продвинутые алгоритмы и структуры данных
- Хранить решения задач и эксперименты в одном месте

## 🛠 Технологии

- Swift
- Xcode Playground — для быстрых экспериментов
- Swift Testing - для тестирования решений

## 📦 Структура проекта

- `Sorting/` — алгоритмы сортировки
(например: Bubble Sort, Selection Sort, Insertion Sort и др.)
- `Searching/` — алгоритмы поиска
(Linear Search, Binary Search и т.п.)
- `LeetCode/` — решения задач LeetCode
- `Playground/` — эксперименты, контесты и черновики
- `*Tests/` — тесты для алгоритмов и задач

Решения Advent of Code живут в отдельном репозитории [advent-of-code](https://github.com/andrewfirsenko/advent-of-code).

## ▶️ Как запустить
